HOUSE RULES

How this store is run

Nobody wants to install a tool for a job that comes up once. The one time the job does come, though, nobody has the hours to go find the tool either. So these shelves hold everything, including things you may never touch, and the day you need one, it is already there. Everything on them is built to the same house standard: a backup lands before your file changes, the work is checked after, and when something cannot be done, your AI says so plainly instead of guessing. The spec sheets hang in each aisle.

Everything plus the kitchen sink.

One server per document format, complete enough that your agent never has to shop anywhere else.

Engineered not to corrupt.

Atomic validated saves, automatic backups before every change, byte-identical passthrough of everything untouched, and adversarial test evidence published with every release.

Refuses rather than guesses.

When a target is ambiguous, the tools refuse and show the candidates. A confident wrong edit is the one product this store does not stock.
